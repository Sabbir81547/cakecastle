# WhatsApp Setup Guide for Cake Castle

## Overview

This guide explains how to set up WhatsApp for your cake business. There are two options:

1. **WhatsApp Business App (FREE)** - Recommended for small businesses
2. **WhatsApp Business API (PAID)** - For larger businesses with automation needs

### Step 5: Create Catalog (Optional)

Show your cakes directly in WhatsApp:

1. Go to **Business Tools** → **Catalog**
2. Add products with:

## Option 2: WhatsApp Business API (PAID)

### When to Use API

Use the API only if you need:
- Automated chatbots
- Integration with CRM systems
- Sending bulk notifications
- Multiple agents on one number

### Pricing

- **Meta Cloud API**: Free for first 1,000 conversations/month
- **Business Solution Providers (BSPs)**: Varies (Twilio, MessageBird, etc.)

### Setup Requirements

1. Facebook Business Manager account
2. Verified business
3. Technical implementation
4. Monthly costs for messages

**Recommendation**: For Cake Castle, the **free WhatsApp Business App** is sufficient. Only consider API if you're handling 100+ orders daily.
